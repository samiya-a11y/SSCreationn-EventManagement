# SS Creationn - Luxury Event Management System
Built with ASP.NET Core MVC (.NET 8.0), EF Core, and SQLite.

## How to Run:
1. Open the project folder in VS Code or Visual Studio.
2. Open Terminal and run:
   dotnet build
   dotnet run
3. Open browser at https://localhost:xxxx
4. Admin Login:
   - Username: admin
   - Password: admin@sscreationn
